# AI Agent Instructions — umbra

Headless React dialog library with zero shipped UI and zero runtime dependencies. This file indexes all documentation and automation available to coding agents across VS Code, Cursor, Windsurf, and other IDE integrations.

## Quick Start

**Build & test:** `yarn install` → `yarn dev` (playground on port 3000) → `yarn test`

**Key constraint:** Never add UI components to `src/` — the library is headless. Users bring their own MUI, vanilla, Tailwind, etc.

## Hard Constraints (Never Violate)

- **Headless-first:** Zero shipped UI. Users own all rendering.
- **No abstraction leakage:** Template hooks don't expose `DialogStoreSnapshot`, lifecycle refs, or store internals.
- **No `useMemo`/`useCallback`/`React.memo`:** React Compiler handles memoization (see [React Compiler Rules](#react-compiler-rules)).
- **Every change to `src/` includes tests** — unit (`*.test.ts`) and/or component (`*.ct.tsx`).
- **Top-layer rule:** Buttons clickable while a dialog is open must live inside `render()` — not in outer harness.

## React Compiler Rules

Target: `babel-plugin-react-compiler` v19

| Rule                                            | Why                                                                                         |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------- |
| ❌ Never `useMemo`, `useCallback`, `React.memo` | Compiler auto-memoizes based on dependencies                                                |
| ❌ No ref writes during render                  | Use `useEffect` for ref updates; prefer `GetDialog` getter pattern                          |
| ⚠️ Store creation in `useState`-init            | `const [init] = useState(() => createStore())` — not `useRef` (avoids ref-tainting)         |
| ✓ Map writes are safe                           | Handler registries `Map<string, handler>` don't count as ref writes                         |
| ✓ Stable identities                             | `open()`, `openAndWait()`, `handle` keep same reference — use in dependency arrays directly |

**Deep dive:** [src/CLAUDE.md](src/CLAUDE.md#react-compiler)

## Vocabulary (Exact Spellings)

| Concept                      | The word                     | Not                               |
| ---------------------------- | ---------------------------- | --------------------------------- |
| `showModal()` vs `show()`    | **modal / non-modal**        | blocking/non-blocking             |
| Template that built a dialog | **`template`**               | kind, type, category              |
| Unconditional transition     | **`beginOpen`**              | requestOpen (that asks)           |
| Closed with nobody acting    | **`DISMISS_REASON`**         | 'dismiss' anywhere in src/        |
| Work an open waits on        | **`prepare`**                | onOpen (that reports)             |
| Caller who may refuse        | **`on…Request`**             | plain `on…` (read return value)   |
| Per-item flag                | **one word**                 | hang it off the object            |
| Slide axis                   | **`direction`**              | anything else calling itself that |
| Tab order step               | **`forwards` / `backwards`** | next/previous                     |

## File Structure

```
src/
  ├─ core/        Framework-agnostic: dialog lifecycle, placement, styles
  ├─ store/       Hand-rolled reactive cell (no deps)
  ├─ actions/     Action factory, hotkey dispatch
  ├─ react/       React binding: useDialog, hooks, outlet
  ├─ solid/       Solid binding: same surface as React
  ├─ vanilla/     Controller binding: for pre-written <dialog>
  ├─ manager/     Dialog manager (global registry)
  └─ utils/       Helpers: normalize-error, dialog-scope, hotkey-utils

playground/
  ├─ src/entities/dialog-template/ui/{mui,vanilla}/  Template components
  ├─ src/pages/<route>/examples/                      Example code
  └─ src/shared/lib/                                  Reference patterns (createMutex, etc.)
```

## Code Style at a Glance

- **Files:** kebab-case (`use-dialog.tsx`, `dialog-manager.ts`)
- **Exports:** PascalCase types/components, camelCase functions/hooks
- **Imports:** `import { useState, type ReactNode } from 'react'` (inline type imports)
- **Optional props:** `| undefined` suffix required (`exactOptionalPropertyTypes` enabled)
- **Arrow params:** Always parenthesized `(arg) =>`
- **Curly braces:** Always required (no implicit returns)
- **Section comments:** Unicode box-drawing `// ── Section Name ────────────────`
- **Enums:** Use `as const` objects, not TS enums
